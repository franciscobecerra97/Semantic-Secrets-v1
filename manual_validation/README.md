# Manual experiment audits

These folders contain learning and diagnostic work, not completed v4 evidence. The active direction is [research direction v4](../docs/research_direction_v4.md); every new diagnostic or experiment needs the explained scope and authorization in [phase workflow](../docs/phase_workflow.md).

- [Historical P9-v2 walkthrough](walkthrough_test/p9-v2/README.md).
- [Separate API walkthrough](walkthrough_test/p9-v2-2/README.md), using the shared v3 images.
- virtual_language_model_test/: exploratory generation and perception API scripts.
- feature_extraction_test/ and semantic_graph_proposal_v1/: exploratory extraction/graph experiments.

The moved walkthrough scripts still contain audited repository-root defects; links here reflect the current directory layout, but this documentation update does not repair or run the scripts.

All 240 v3 images exist under artifacts/downloads/p9_v3. Naturalistic final references and the ground-truth freeze remain pending. No common v4 precision result is established. See [the v3 dataset guide](../docs/p9_v3_remote_dataset.md) for that branch's provenance.

Historical inputs/results remain immutable. Diagnostics retain their own outputs/provenance and never overwrite or relabel a formal experiment. Existing loose array/graph prompts are not the frozen v4 observation contract.
