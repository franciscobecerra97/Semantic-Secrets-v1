\title{Semantic Secrets: Private Authentication from Reconstructable Visual Semantics}

\begin{document}

\begin{abstract}
This planning manuscript defines a revised research direction; it does not report a completed system or v2 experiment. We ask whether a remembered visual concept can be reconstructed through independently generated images, converted locally into a canonical typed semantic graph, and privately verified under a system-derived policy. The prompt is a reconstruction interface rather than the secret, and generated pixels are transient observations rather than entropy. The intended contributions combine technical reconstruction stability, mandatory-versus-tolerant semantic policy, acceptance-region attacks under finite budgets, and construction-specific private and unlinkable verification. A complete review of 2026 Visual Semantic Authentication (VSA) makes clear that image-independent semantic authentication, canonical visual tokens, object/attribute/count/quadrant rules, and flexible quantity policies are prior art. The prospective privacy contribution must therefore be established relative to VSA, fuzzy/private matching, protected templates, and established cryptographic primitives. Frozen negative P6/P7 evidence from the earlier v1 pipeline is retained only as formative motivation. The next phase is novelty refresh and preregistration, not implementation.
\end{abstract}

\maketitle

\section{Problem and scope}

Authentication based on approximate semantic meaning has an unusual tension. Benign reconstructions must vary, yet every tolerated variation enlarges the set an attacker may submit. If a server stores a deterministic semantic verifier, the same structure that permits fuzzy acceptance may reveal semantic content, support offline candidate testing, or link reuse across services. Secure computation may hide the comparison while leaving the accepted region easily enumerable.

We study a prospective client-side pipeline in which a person reconstructs a remembered visual concept using free natural language. A local generator produces a new image, and a local extractor maps that image into a canonical semantic representation. The strongest target sends neither prompt, image, plaintext graph, nor raw embedding to the authentication infrastructure.

No participant study is planned. Researcher-authored concepts and reconstructions can measure only technical semantic reconstruction stability. They cannot establish memorability, recall, usability, preference, or natural credential choice.

\section{The prompt and image are not the secret}

Let $C$ denote a remembered visual concept and $P$ a free-form reconstruction prompt. Different expressions may aim at the same concept---for example, ``a cat beside a red car'' and ``a feline next to a crimson automobile.'' The hypothesis is not exact prompt reproduction. With generator $G$ and randomness $r$,
\begin{equation}
  I = G(P,r),
\end{equation}
where $I$ is a transient, independently generated image. Pixels do not contribute password entropy merely because generation is stochastic. A versioned extractor $E$ produces
\begin{equation}
  S = E(I).
\end{equation}
The credential source is the canonical semantics and, operationally, the complete set of candidate semantics the verifier accepts.

This framing differs from treating direct text embeddings or a single generated image as the authentication object. It also creates a falsifiable condition: if independent generation and fresh extraction do not preserve security-relevant structure, the visual reconstruction hypothesis fails.

\section{Canonical policy-aware semantics}

We provisionally represent $S$ as a typed graph
\begin{equation}
  S=(V,E_S,A,C_S),
\end{equation}
where $V$ contains entities, $E_S$ typed actions/relations, $A$ attributes, and $C_S$ counts and scene/context facts. A deterministic, versioned policy derivation function produces
\begin{equation}
  \Pi(S)=(M,T),
\end{equation}
where $M$ contains mandatory security anchors and $T$ contains secondary facts with bounded tolerance. The primary non-human study will not ask users to nominate $M$ or $T$. Selection must be frozen from independent semantic rationale, training-only statistics, extractor reliability, attacker-frequency evidence, and protocol compatibility.

A candidate reference functionality has the form
\begin{equation}
  \mathsf{Accept}_{\mathrm{ref}}=\mathsf{MandatoryOK}(M,M')
  \land [\mathsf{TolSim}(T,T')\geq\tau],
\end{equation}
but the exact graph, operators, missing-value rules, and threshold remain to be preregistered. The notation and policy split are not claimed as standalone novelty.

\section{Acceptance-region security}

For an enrolled state, define the accepted region
\begin{equation}
  \mathcal{A}(S,M,T)=\{(S',M',T'): \mathsf{Accept}_{\mathrm{ref}}=1\}.
\end{equation}
An attacker succeeds by finding any member, not by recovering the enrolled prompt, image, or exact graph. We distinguish:

\begin{itemize}[leftmargin=*]
  \item $K_0$: generic public knowledge and random candidates;
  \item $K_1$: population or frequency knowledge without target facts;
  \item $K_2$: partial target-specific semantic information;
  \item $K_3$: strong near-secret information.
\end{itemize}

For strategy $Q$, budget $B$, knowledge $K_i$, and observable view $V$, the primary quantity is
\begin{equation}
  \mathsf{Succ}(Q,B,K_i,V)=
  \Pr[\exists j\leq B: q_j\in\mathcal{A}(S,M,T)].
\end{equation}
The evaluation should report success@1, @5, @10, and @$B$, guesses to success, duplicate policy, uncertainty, and cost. Random FAR is only one distributional statistic. Frequency, targeted neighbours, partial knowledge, LLM/VLM/generator assistance, and adaptive semantic search may produce different risk. AI-assisted password guessing is established prior art~\cite{Rando2023PassGPT}; this project must contribute a semantic acceptance-region analysis rather than the general idea of using a model to guess.

\section{Privacy target}

The protected record is abstractly
\begin{equation}
  R=\mathsf{Protect}(S,M,T,\mathsf{account},\mathsf{domain},\mathsf{version}).
\end{equation}
A later protocol should reproduce the frozen plaintext decision while revealing no more than its declared output and metadata. Candidate goals are:

\begin{itemize}[leftmargin=*]
  \item template confidentiality against semantic recovery or accepted-equivalent reconstruction;
  \item resistance to cheap database-only candidate validation under an exact stolen-record view;
  \item policy privacy for anchor identities, operators, weights, thresholds, and graph shape;
  \item unlinkable, domain-separated records and transcripts;
  \item transcript minimisation, replay/session binding, and explicit adaptive-query leakage;
  \item containment under named database, server, key/share, collusion, and total-compromise states.
\end{itemize}

Established fuzzy extractors~\cite{Dodis2008FuzzyExtractors}, OPRFs~\cite{Davidson2023OPRF}, OPAQUE~\cite{Bourdrez2025OPAQUE}, PSI~\cite{Pinkas2015Phasing}, fuzzy PSI/private biometric matching~\cite{Uzun2021FLPSI}, and homomorphic vector matching~\cite{Martin2025HyDia} are candidate foundations, not novel primitives. Raw learned representations are not automatically private; embedding leakage is an explicit concern~\cite{Song2020EmbeddingLeakage}. Protected-template unlinkability and irreversibility must be attacked rather than inferred from an encoding~\cite{GomezBarrero2016Unlinkable}.

Semantic correctness and cryptographic privacy are independent. FAR/FRR do not prove privacy; private computation does not repair an easily guessed acceptance region.

\section{Closest work and VSA boundary}

VSA~\cite{Jeong2026VSA} is the closest mandatory baseline. It enrols a reference image, extracts objects, CLIP-derived attributes, quantities, visibility, and 2$\times$2 quadrant location, and lets a user select two or three semantic facts plus quantity operators. Authentication uses an arbitrary satisfying image and an additional password. VSA serialises canonical semantic tokens, evaluates Flexible Range Logic conjunctions, hashes most semantic fields together with the password using SHA-256, and retains quantity/operator metadata separately.

These features remove image-independent visual-semantic authentication, VLM extraction, canonical tokens, object, attribute, count, and quadrant rules, flexible quantity policies, conjunction, and user-selected semantic policy from our novelty space. We require two fair baselines: (i) VSA's semantic-policy component for functional discrimination and (ii) the full semantic-plus-password hash architecture for security comparison. We must not compare a semantic-only system directly with VSA's claimed combined semantic-plus-password space as though the credentials were equivalent.

VSA calls its hash binding server-opaque and explicitly weaker than strict zero knowledge. It acknowledges small semantic inputs and fast SHA-256 offline guessing, recommending Argon2id with a user-specific salt. Its COCO-based positive FRR samples are automatically selected from cached detections rather than independently re-inferred. It reports no human study and leaves Semantic Relationship Logic to future work. It does not target private/unlinkable verification.

SemanticLock uses semantically linked image tokens and story structure for graphical authentication~\cite{Olade2023SemanticLock}, further preventing broad ``first semantic graphical password'' language. The remaining hypothesis is the evaluated combination of independent generative reconstruction, typed visual-semantic graphs, system-derived mandatory/tolerant policy, acceptance-region attacks, and private/domain-separated verification. P8 must test whether broader prior work already subsumes that combination.

\section{Research questions}

\begin{sloppypar}
\begin{enumerate}[leftmargin=*,label={}]
  \item \textbf{RQ1---Reconstruction.} Can independently generated images representing the same intended visual concept produce stable canonical semantic credentials?
  \item \textbf{RQ2---Policy-aware matching.} Can a system-derived $S=(M,T)$ policy preserve legitimate technical reconstruction variation while rejecting security-critical semantic differences?
  \item \textbf{RQ3---Acceptance-region security.} How vulnerable is the induced accepted region under $K_0$--$K_3$ attackers and finite budgets?
  \item \textbf{RQ4---Template/privacy leakage.} What semantics can be inferred from stored records, policies, and authentication transcripts under named compromise views?
  \item \textbf{RQ5---Private verification.} Can the frozen policy be evaluated while hiding the semantic credential and resisting practical database-only validation and cross-domain linkage under stated assumptions?
  \item \textbf{RQ6---Practicality.} What computation, bandwidth, latency, storage, trust, and deployment assumptions are required?
\end{enumerate}
\end{sloppypar}

\section{Proposed methodology and baselines}

The execution order is deliberately staged.

\paragraph{Novelty and preregistration.} P8 completes a primary-source novelty refresh and freezes graph tasks, controlled concepts, splits, capability screening, policy derivation, attack budgets, and gate thresholds. It performs no expensive experiment.

\paragraph{Representation before authentication.} P9A screens a small preregistered set of extractors on images with known object, attribute, count, action, relation, and context ground truth. P9B then measures independent generative reconstruction across paraphrases, seeds, layouts, justified styles, and selected version drift. Direct text is an ablation, not the target credential path.

\paragraph{Policy and attackers.} P10 compares dense similarity, global fuzzy overlap, a feasible VSA-style policy, and the proposed system-derived $M/T$ policy. P11 evaluates the full acceptance region under budgeted attackers before any cryptographic implementation.

\paragraph{Private verification.} Only a constructive semantic-security gate permits P12 to define the ideal functionality and compare mature constructions. Minimal POCs precede selection. The selected protocol is then evaluated for reference correctness, leakage, offline validation, compromise, linkage, and cost.

\paragraph{Baselines.} Planned baselines include direct-text processing, dense visual/text similarity, global fuzzy semantic overlap, VSA semantic-policy behaviour, the full VSA binding model where reproducible, plaintext/hash records, and relevant mature private-matching constructions. Any inaccessible or underspecified VSA behaviour will be documented rather than guessed.

\section{Decision gates}

The gates are: V2-N novelty viability; V2-A visual-semantic reconstruction viability; V2-B policy-aware semantic viability; V2-C acceptance-region security viability; V2-D private-functionality viability; V2-E protocol selection/privacy viability; and V2-F end-to-end evidence/paper story. No later cost may bypass an earlier failure. Valid outcomes include standalone authentication, second factor, policy-constrained credential, measurement/negative contribution, or stop.

\section{Formative v1 evidence}

The completed P0--P7 programme evaluated a different system, \texttt{visual-semantic-pipeline-v1}. P6's training-selected weighted matcher had validation FRR 20.8\%, targeted-neighbour FAR 75.0\%, and random FAR 3.0\%; all tested representations failed the original gate. Twelve v1 test families remain sealed. P7 then found no uncertainty-supported material benefit from the tested SD-Turbo/Florence/SigLIP image pathways and removed that image stage from the v1 authentication core.

These are immutable formative negative results, not v2 measurements. They motivate explicit security anchors and independent capability screening but may not tune the v2 policy, representation, data, or gates. The v2 hypothesis requires new identifiers, preregistration, and evidence.

\section{Expected contributions and limitations}

If all gates pass, C1 would establish technical generative reconstruction behaviour; C2 would establish the measured value of a system-derived typed policy; C3 would characterise the accepted region under realistic finite-budget attackers; and C4 would establish construction-specific private and unlinkable verification. C3/C4 are expected to carry the principal privacy contribution. C5, adaptive semantic verification-oracle leakage, remains optional and will be folded into C3/C4 unless P8 identifies a distinct result.

Major unresolved risks are that independent visual extraction is not stable, $M/T$ adds no value over VSA-style policy, the semantic region is cheaply reachable, the privacy construction is an obvious application of known primitives, policy metadata recreates an offline oracle, or the required trust/cost is impractical. The controlled methodology cannot establish human memorability or usability. A future participant study would require separate ethics, design, and evidence.

\section{Conclusion}

This blueprint treats visual generation as a testable reconstruction layer, not a source of magical entropy, and treats privacy as a construction-specific property, not a consequence of hashing semantics. The next permitted work is P8 novelty, formalisation, and preregistration. No v2 model, dataset, experiment, or cryptographic prototype is yet authorised.
