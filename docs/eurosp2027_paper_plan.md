Direction approved on 26 October 2026 under DIRECTION-V4-01. This is manuscript preparation, not completion of P18-v4 or authorization to execute a phase.

## Narrative and claims

Working title: **Semantic Secrets: Reconstruction and Security-Relevant Semantic Distinctions in Visual Authentication**.

Lead with the security tension: reconstruction must tolerate legitimate variation, while perception/normalization can erase differences and create accepted alternatives. Investigate which distinctions survive, how they fail and how those failures affect a frozen authentication predicate. Model comparison serves this question.

Proposed contributions are V4-C1 (error-to-authentication methodology), V4-C2 (empirical distinction preservation/collapse), and V4-C3 (independent reconstruction plus finite-budget attacks). These are not completed findings. Refresh novelty for the actual v4 scope; the earlier P8 review does not automatically establish it.

Explain generation fidelity, image extraction, graph binding, normalization, reconstruction and attacker success as separate evaluation layers. Use author-authored final-image truth. Generated images are primary workflow evidence, controlled drawings diagnostic, photographs external generalization. Exact source/model/task choices await design approval.

Historical P9-v2 is a bounded schema-failure observation, not a head-to-head semantic comparison. P9-v3 provides preparation, not an accuracy result. The two VSA comparators remain distinct: semantic-policy behavior and full semantic-plus-password architecture. Do not imply universal architectural superiority from two named pipelines.

Private verification remains a separate deferred project goal. It is discussed as a trust limitation and future construction requirement, not a promised principal result. This authorized scope change does not pass the original C4/V2-D/V2-E gates. If future private evidence exists, an explicitly approved scope revision can incorporate it.
