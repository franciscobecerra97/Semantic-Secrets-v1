P9-v3 naturalistic reference authoring

Inspect each final image and record visible facts. Prompts and extraction-model predictions are deliberately absent.

Do not invent missing objects or relationships. Flag unclear or unsupported images. All references must be completed before extraction.

Drag a tight box around each visible entity. Boxes use normalized coordinates. Include two to four main entities under the frozen naturalistic design.

Visible semantic facts

Entity facts, exact category counts and box geometry are derived automatically from your boxes. Add colours, interactions, scenes and applicable exploratory facts yourself. For a scene, source and target are ignored; unary facts use source only.
